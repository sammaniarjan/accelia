# BRON — landingspagina (werktitel)

Pre-launch landingspagina voor een webshop in ultra-verse, single-estate Spaanse
olijfolie (Picual & Arbequina), direct bij de pers ingekocht bij Hacienda San Miguel,
Alhama de Murcia.

## Stack

Eén statisch bestand: `index.html`. Geen build, geen dependencies. Open het bestand in
de browser of host het op elke statische host (Netlify, Vercel, GitHub Pages, Cloudflare
Pages).

## Aanpassen

- **Naam**: "BRON" is een werktitel — zoek/vervang in `index.html`.
- **E-mailformulier**: het formulier heeft een `TODO` in het script onderaan
  `index.html`; koppel daar Formspree, MailerLite of een eigen endpoint aan.
- **Oogstdata en aantallen**: hero-specblok en Oogstclub-sectie bevatten
  plaatshouderwaarden (oogst november 2026).
